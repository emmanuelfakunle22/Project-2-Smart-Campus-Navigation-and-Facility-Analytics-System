Issues found
------------
1. FacilityDatabase::load() checked table.contains(id) first, then called
   table.insert(fac) without using its return value. If insert() ever
   failed, the facility would still be pushed onto the display list, so
   the list and the hash table could disagree.
   Fix (by Emmanuel): load() now uses insert()'s return value as the
   duplicate check and only adds to the list when insert() succeeds.
   Re-ran testdata/collision and testdata/badrecords: same warnings and
   summaries as before (duplicate F013 and F001 still rejected).
